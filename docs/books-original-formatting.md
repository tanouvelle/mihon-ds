# Original book formatting

## PDF

PDF support renders each original page with Android PdfRenderer. It preserves the page layout, illustrations, tables, code and equations rather than extracting text. Original page dimensions and aspect ratios are retained; rendered images are bounded to 1800 by 2400 pixels. The standard image reader supplies zoom, page progress and paired-screen reading. This update does not change the PDF rendering path; the earlier PDF-support patch remains a prerequisite for reading PDFs.

## EPUB

Original formatting is the default EPUB mode in this update. It serves the original publisher XHTML, CSS, embedded fonts, SVG and images from the EPUB manifest into a native WebView. Text is not extracted or rebuilt for display. Scroll within a document, use Previous/Next to move by a viewport and then between spine documents, pinch to zoom, or choose a chapter from Contents. Static internal links and same-document footnotes can be followed. Remote resources, file/content access and book scripts are disabled. Resources are limited to 16 MiB per entry.

This first implementation uses the main screen for original-format EPUB reading. The companion page view displays a mode notice instead of a differently formatted text page. Previous/next controls route to the original reader while it is open. PDF and the existing paged text reader continue to support paired screens. EPUBs remain responsive to publisher CSS; their layout is not guaranteed pixel-identical to a printed edition. Math generated by JavaScript, external resources, DRM and non-spine footnote documents are not supported. Static SVG/MathML support depends on the installed Android WebView.

Switch modes in Reader settings > EPUB > Original formatting or Selectable text. A book's selection is saved independently. Font and theme controls affect the text reader, leaving original publisher styles intact. Closing original mode returns to the standard paged reader; reopening the book uses its saved mode.

Original mode saves its spine document and proportional scroll location independently of the text reader's position. On mode switches it maps progress approximately into the corresponding text pages. Original location and mode selection are included in EPUB backups. Rotation and device-size changes restore a proportional location rather than an exact word position.
